# Birthday Surprise 🎀

A cute, interactive birthday surprise website in a soft 3D claymorphism style.

**Live site:** https://cyberrrana.github.io/birthday-surprise/

## Personalize

Open `index.html` and change a single value:

```js
const CONFIG = { name: 'Pookie' };
```

Every heading, the letter and the finale update automatically. Colors live in the `:root` CSS variables at the top of the stylesheet.

## What's inside

1. Gift-box landing screen with confetti opening
2. Birthday celebration with cake and floating balloons
3. Three love cards (reminder / wish / virtual hug)
4. Blow-the-candles wish interaction
5. Envelope with a handwritten letter
6. Final one-last-hug surprise

Built with plain HTML, CSS and JavaScript — no build step, no dependencies, mobile-first, and `prefers-reduced-motion` friendly.
